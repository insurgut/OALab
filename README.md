# OALab

Монохромное Android-приложение для поиска аниме, локальной библиотеки и воспроизведения доступных пользователю видеопотоков.

**Статус:** проект в разработке. Не заявляется интеграция с 50 стриминговыми сервисами: публичные каталоги аниме и лицензионные видеопотоки — разные вещи.

## Возможности

- Kotlin + Jetpack Compose + Material 3; 5 вкладок с плавающей навигацией.
- Публичные каталоги AniList и Jikan без регистрации; категории, поиск, сортировка.
- Избранное, статусы, история и рекомендации по любимым жанрам сохраняются на устройстве.
- Media3 ExoPlayer; воспроизведение HLS/MP4/DASH, перемотка, скорость, внешние субтитры, выбор дорожек.
- Импорт пользовательских HTTPS JSON-фидов для серий и озвучек; переключение вариантов до просмотра и внутри плеера.
- Сортировка озвучек по популярности, голосам, количеству оценок, таймингам и названию.
- Настройки языка, предпочтений, плеера и источников.
- Никаких логинов, аккаунтов и облачного слежения.

**Важно:** AniList и Jikan отдают метаданные, а не видео. Для просмотра серий добавьте фид, содержащий URL видео, которые вы вправе воспроизводить. Приложение не обходит DRM, вход или платные ограничения.

## Сборка

В GitHub Actions после push в `main` запускается `Android Debug APK`. Файл находится в артефакте `OALab-debug-APK` в соответствующем запуске. Локально: Android SDK API 36, JDK 17, Gradle 8.13: `gradle :app:assembleDebug`.

## Пример фида

```json
{
  "name": "Моя медиатека",
  "entries": [
    {
      "anilistId": 1,
      "malId": 1,
      "title": "Cowboy Bebop",
      "episodes": [
        {
          "number": 1,
          "streams": [
            {
              "url": "https://media.example.org/episode-01.m3u8",
              "team": "Оригинал",
              "language": "ja",
              "voices": 1,
              "votes": 0,
              "popularity": 0,
              "timing": "original",
              "subtitle": "https://media.example.org/episode-01-ru.vtt"
            }
          ]
        }
      ]
    }
  ]
}
```

Можно импортировать несколько фидов; одинаковые тайтлы сопоставляются по AniList ID, MAL ID или названию. При изменении фида нажмите «Обновить». Источники должны использовать HTTPS и отдавать корректные ссылки на поддерживаемые видеопотоки.

## Безопасность и ограничения

- Нет встроенных нелицензированных зеркал и обхода авторизации/DRM.
- Фиды добавляет сам пользователь; URL и их содержимое считаются недоверенными.
- Список официальных ссылок, выдаваемых AniList, может отличаться по региону.
- Озвучки, голоса, рейтинг и тайминги зависят от фактических данных фида. Приложение не выдумывает эти метрики.
- Настройки и библиотека локальные; удаление данных приложения удалит их.
