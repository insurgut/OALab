# Архитектура OALab (0.1.0)

## Техническая основа
- Kotlin 2.2.20; Jetpack Compose + Material 3, Android 8.0+.
- Android Gradle Plugin 8.13.2, Gradle 8.13, compileSdk 36.
- Compose BOM 2026.06.01: совместим с AGP 8.13 в отличие от BOM 2026.09.
- Media3 ExoPlayer 1.11.1: HLS, DASH и прогрессивные видеопотоки MP4, отдельные дорожки и WebVTT/SRT субтитры.
- Coil: загрузка и кэширование обложек без отдельной авторизации.
- Сеть: публичный GraphQL AniList и Jikan REST; на устройстве только HTTPS.
- Нет аналитики, аккаунтов, обязательных сервисов Google или серверов пользователя.

## Экранная структура
1. Главная: герой с обложкой, подборка, рекомендации по пользовательской библиотеке и продолжение просмотра.
2. Каталог: поиск, жанры, сортировки, постеры, рейтинги, пагинация.
3. Моё: избранное, статус «Смотрю», «Просмотрено», «В планах», «Брошено», прогресс.
4. Источники: добавление/обновление/удаление HTTPS JSON фидов с доступными потоками.
5. Настройки: каталог AniList/Jikan, приоритет языка и озвучки, шаг перемотки, автовоспроизведение, оформление и приватность.
6. Детали тайтла: описание, трейлер, избранное/статус, выбор эпизода и озвучки до запуска.
7. Плеер: управление, ориентация, скорость, аудио и субтитры, альтернативные варианты озвучек без выхода из плеера.

## Модель данных
- `Anime`: аниме, идентификаторы AniList/MAL, названия, метаданные, жанры, обложка.
- `LibraryEntry`: локальные статусы, избранное и прогресс воспроизведения.
- `SourceFeed` → `SourceEntry` → `StreamVariant`: источник, animeId, эпизод и доступные озвучки.
- `LocalLibrary`: Android SharedPreferences и приватные файлы, без внешней базы.
- Сопоставление тайтлов — по AniList ID, MAL ID или названию. Приоритет сопоставления — ID.

## Безопасность и границы
- AniList/Jikan — метаданные, **не видеохостинги**. Доступ к видео не гарантируется.
- Не встроены зеркала с сомнительными правами, обход DRM, вход без разрешения и скрытые парсеры.
- Импортируемые источники требуют HTTPS. Каждый поток и субтитры из фида также требуют HTTPS.
- Пользователь самостоятельно предоставляет источники, доступные на законных основаниях.
- Нет выдуманных голосов, рейтингов и таймингов: метрики показываются только из фида.
- Нет синхронизации между устройствами; данные удаляются вместе с данными приложения.
- Демо-APK подписывается стандартным отладочным ключом GitHub Actions, **не подходит для публикации в Google Play**.
- Количество подключаемых фидов не ограничено приложением; готовых 50 стриминговых интеграций нет.

## Дальнейшие инженерные задачи
- UI-тестирование на телефонах и планшетах, улучшение TalkBack/контрастности и размеров текста.
- База данных Room и миграции, чтобы сохранять историю большого каталога.
- Подтверждённые интеграции только с сервисами, которые предоставляют официальные API и нужные права.
- Управление скоростью/буфером, PiP, автоматический выбор дорожки по языку и сохранение положения каждой серии.
- Автотесты API-фолбэка, парсинга фидов, сопоставления и порядка озвучек.

## Доставка
Каждый push в `main` собирает debug APK через GitHub Actions. Успешная сборка публикует `OALab-debug.apk` в GitHub Release `v0.1.0`. Внутри репозитория доступен весь код; PR не создаётся.
